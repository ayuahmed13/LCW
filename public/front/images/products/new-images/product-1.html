Description

This mini receiver / controller works with single colour LED strip using APP control through WiFi or Bluetooth.  It uses either the Tuya or Smart Life App and can also be linked to Amazon and Google Home. The Smart Life app allows additional control using IFTTT.

Ideally suited to smaller LED strip installations.

 

FEATURES:

  • Output power: 3.5A, 42W @ 12V / 84W @ 24V
  • Smooth dimming without flicker
  • Range dependant of WiFi or Bluetooth strength
  • Insulated input and output wires (120mm)
  • Indoor applications only (IP20)
